Excel + imágenes

Sube el Excel de Caneva y, si quieres, también las fotos desde el computador. El sistema guarda productos en Cloudflare KV y fotos en Cloudflare R2. La web y Caneva AI usan esa base sin tocar código.

El token autoriza la publicación. Solo queda guardado en este navegador si marcas Recordar token.

Columnas esperadas: Categoría, Nombre, Precio, Descripción, Variantes / Tallas, Stock, Imagen Principal, Imágenes Extra, URL Producto, Tela (opcional).

En el Excel, la columna Imagen Principal puede traer una URL o el nombre del archivo: bota-recta.jpg. Si la celda queda vacía, el sistema intenta emparejar por nombre del producto.

Después de publicar, copiar a Cloudflare R2 las URLs externas actuales y reemplazarlas por URLs propias del Worker.
